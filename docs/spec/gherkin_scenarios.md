Feature: 智慧因子投資策略 MVP 測試規範



&#x20; Scenario: 股票池流動性篩選測試

&#x20;   Given 全市場存在 1000 檔上市櫃股票

&#x20;   When 計算過去 20 個交易日平均成交金額

&#x20;   Then 應剔除排名最後 200 檔股票

&#x20;   And 最終股票池保留前 800 檔標的



&#x20; Scenario: 因子數據標準化驗證

&#x20;   Given 原始因子數據存在極端離群值

&#x20;   When 執行去極值與 Z-score 標準化

&#x20;   Then 因子平均值應趨近於 0

&#x20;   And 標準差應趨近於 1



&#x20; Scenario: 扣除交易成本之淨值計算

&#x20;   Given 本期月調倉換手率為 50%

&#x20;   When 計算本期策略投資報酬

&#x20;   Then 應扣除 50% \* (雙邊手續費 0.285% + 證交稅 0.3% + 雙邊滑價 0.2%) 的交易成本

&#x20;   And 輸出扣除成本後的實際淨值



&#x20; Scenario: 樣本外期間數據隔離驗證

&#x20;   Given 樣本外回測設定為 2023-01 至 2026-09

&#x20;   When 執行樣本外驗收回測

&#x20;   Then 模型不得引用 2023-01 之後未公開之未來數據 (No Look-ahead Bias)

&#x20;   And 僅能使用歷史已公告財報與價格



&#x20; Scenario: 自動化測試與重現性驗證

&#x20;   Given 開發者下載專案原始碼

&#x20;   When 在終端機執行 `python main.py`

&#x20;   Then 系統必須在 3 分鐘內完成全流程運算並輸出績效圖表
