\# ADR 0001: 智慧因子投資 MVP 技術架構選擇



\## Status

Accepted



\## Context

本專案為第 2 週 MVP 交付物，需建立具備可重現性、模組化且方便後續 8 週擴充機器學習模型的台股因子投資 Baseline 系統。



\## Decision

1\. \*\*開發語言與核心庫\*\*：使用 Python 3.10+，結合 `pandas` 與 `numpy` 進行向量化數據處理與因子計算。

2\. \*\*回測引擎\*\*：採用自研輕量級 Pandas-based 向量化回測引擎，確保月調倉處理與成本計算透明可控。

3\. \*\*基準對比\*\*：採用「臺灣加權報酬指數（含息）」做為 Benchmark，確保配息計算不失真。



\## Consequences

\* \*\*優勢\*\*：向量化運算執行極快（< 10 秒），程式碼架構乾淨，方便後續替換智慧選股模型。

\* \*\*劣勢\*\*：簡化盤中頻率細節，僅關注月頻率調倉結算。
