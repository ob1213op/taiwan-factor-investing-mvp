\# 台股智慧因子投資策略 MVP (Taiwan Factor Investing MVP)



本專案為台股因子投資策略 Baseline 流程，支援自動化資料處理、因子計算、扣除交易成本之樣本外回測與對比基準指數。



\## 📁 專案目錄架構

\* `docs/spec/`: 需求與設計文件 (User Stories, Gherkin 情境, ADR)

\* `src/`: 核心邏輯 (流動性過濾、因子計算、選股與回測引擎)

\* `tests/`: 自動化測試腳本

\* `ai\_log/`: AI 協作日誌 (Prompts, 錯誤與修正)



\## 📊 策略規格與參數設定

\* \*\*股票池\*\*: 上市櫃普通股，剔除前 20 日均成交金額最低 20% 股票

\* \*\*樣本內期間\*\*: 2015/01 \~ 2022/12

\* \*\*樣本外期間\*\*: 2023/01 \~ 2026/09

\* \*\*因子 (5個)\*\*: EP (價值), BP (價值), ROE (品質), 營業利益率 (品質), 12-1M Momentum (動量)

\* \*\*交易成本\*\*: 單邊手續費 0.1425% + 證交稅 0.3% + 單邊滑價 0.1%

\* \*\*Benchmark\*\*: 臺灣加權報酬指數 (含息)
